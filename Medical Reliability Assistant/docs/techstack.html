Multi-Agent Pipeline
1 User Query natural language input
2 Input Guardrail OpenAI — safety / PII classification
3 Retrieval Agent ChromaDB + BM25 → RRF → cross-encoder rerank
4 Analysis Agent z-score anomaly detection + correlation summary
5 Maintenance Agent historical pattern matching on incidents
6 Recommendation Agent GPT-4o-mini → structured reliability report
7 Output Guardrail Claude — hallucination check + medical safety filter
8 Human-in-the-Loop approve / edit / reject via /api/review
9 Final Response delivered to engineer
